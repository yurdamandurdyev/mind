# MIND

Локальное пространство заметок с интерактивной нейронной картой. Vanilla JavaScript, Canvas, CSS; зависимости отсутствуют. Node.js 20+ нужен только для локального сервера.

## Запуск

```sh
cd /workspace/mind
npm start
```

Сервер слушает порт 3000 (можно изменить через PORT). `npm test` проверяет формат данных и импорт. Интерфейс адаптирован для телефона и компьютера.

## Возможности

11 сфер жизни и добавление своих, создание/редактирование/удаление заметок, избранное, поиск, фильтрация по сферам, масштабирование и разворот графа, JSON-экспорт и импорт. Начальные заметки — редактируемые примеры. Линии нейронного графа пока декоративные: ручные связи и wiki-ссылки между заметками ещё не реализованы.

Данные сохраняются в localStorage браузера для конкретного адреса сайта. Аккаунт и серверная база не используются. Очистка данных браузера удалит заметки. Регулярно сохраняйте JSON-копии через «Экспорт». Импорт заменяет текущую коллекцию после подтверждения. Синхронизации между устройствами нет.

Service worker кэширует приложение для повторного открытия без сети после первого успешного открытия. Для него и установки на домашний экран нужен HTTPS или localhost; доступность установки зависит от браузера. Это веб-приложение с PWA-манифестом, не нативный пакет для App Store/Google Play. После первой загрузки дождитесь регистрации service worker и обновите страницу перед офлайн-проверкой.

Шрифты системные, внешние сетевые ресурсы не используются. Для обновлений оболочки приложения изменяйте версию кэша в sw.js.
