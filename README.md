# MIND

Личное пространство заметок на **React 19 + Vite**. Нейронная карта с объёмной проекцией двух полушарий, сферы жизни и локальное хранение. Для иконок используется Lucide; визуализация мозга рисуется Canvas без внешних изображений и сервисов.

## Разработка

Нужен Node.js **22.12+** (в облачной среде проверено на 24.19).

```sh
npm ci
npm run dev
```

Vite запускает dev-сервер на порту 3000. `npm start` — тот же режим. При занятом порте Vite выберет следующий; `npm run dev -- --strictPort` запрещает это. После перехода со старого сервера остановите `node server.mjs`, если он ещё работает.

## Сборка и офлайн-режим

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`; preview использует порт 4173. Для размещения отдавайте содержимое `dist/` из корня сайта по HTTPS. `scripts/build-sw.mjs` создаёт service worker с версией по содержимому сборки и списком всех ресурсов. После успешной первой загрузки production-версия открывается и сохраняет заметки без сети. В dev-режиме service worker отключён, чтобы не мешать обновлению модулей.

Это веб-приложение с PWA-манифестом. Возможность установки на домашний экран зависит от браузера; нативные пакеты для магазинов приложений не создавались.

## Данные

- Ключ `mind-universe-v1` и JSON-формат предыдущей версии сохранены. Обновление на **том же origin** подхватит существующие заметки.
- Origin включает протокол, адрес и порт. Между dev, preview, телефоном и размещённым сайтом переносите данные через экспорт/импорт.
- Заметки находятся в `localStorage` браузера. Очистка данных сайта удалит их. Регулярно делайте JSON-копии.
- Импорт проверяет структуру и требует подтверждения замены; текущую коллекцию можно экспортировать прямо в диалоге.
- Ошибки записи не закрывают редактор и не стирают набранный текст. Изменения в других вкладках подхватываются автоматически.
- Начальные заметки — редактируемые примеры. Автоматической синхронизации, аккаунтов и серверной базы нет.

## Возможности

11 исходных сфер и добавление собственных; создание, редактирование и удаление заметок; избранное; поиск (Ctrl/Cmd+K); фильтрация по сферам; фокус-панель; масштабирование, полноэкранная карта и пауза анимации; мобильное меню. Анимация учитывает `prefers-reduced-motion`.

Линии между сферами — визуальная нейронная сеть, а не пользовательские связи заметок. Wiki-ссылки и ручное редактирование связей пока не реализованы.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Если Chromium уже установлен в системе:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Playwright сам поднимает preview. Сценарии проверяют совместимость старых данных, CRUD заметок, избранное и поиск, свои сферы, импорт/экспорт, работу без сети, мобильную навигацию и сохранность текста при заполненном хранилище.

## Структура

- `src/App.jsx` — компоновка и действия приложения.
- `src/components/BrainGraph.jsx` — нейронная карта, Canvas и кнопки сфер.
- `src/components/NoteEditor.jsx`, `Modal.jsx` — редактор и диалоги.
- `src/hooks/useUniverse.js` — чтение, запись и синхронизация локального состояния.
- `src/data.js` — совместимый формат, примеры и валидация.
- `src/style.css` — адаптивное оформление.
